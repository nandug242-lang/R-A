# R A — Android Studio Project

App name: R A
Brand: Rythu Aasara / రైతు ఆసరా

Open this folder in Android Studio and let Gradle sync.
Run on an Android device/emulator.

This version wraps the working mobile web prototype in a native Android WebView.
It includes the supplied Rythu Aasara branding, farmer help flow, donation demo, profiles, notifications and voice-input hook.

Important: donations are DEMO only. Real payments, Firebase authentication/database and farmer verification still need production backend integration.
